🔢 Arrays in Java

This repository contains Java programs that demonstrate the use of **arrays**—one of the most fundamental data structures in programming.  
It covers basic to intermediate operations such as creation, traversal, searching, sorting, and manipulation of arrays.

---

🚀 Features
- Array creation and initialization
- Traversal (using for, while, for-each loops)
- Searching (linear search, binary search)
- Sorting (bubble sort, selection sort, insertion sort)
- Multi-dimensional arrays (matrices)
- Practical examples (sum, average, max/min in arrays)

---

🛠️ Tech Stack
- **Java (JDK 8+)**
- **Core Java concepts**
